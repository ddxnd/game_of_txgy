《天下归一》— 给对方的使用说明
================================

【需要什么】
  整个 tianxia_guiyi 文件夹 + 电脑已安装 Python（免费）

【怎么启动】（任选一种）

  方法一（推荐）
    双击文件夹里的 run.bat

  方法二
    1. 打开本文件夹
    2. 在上方地址栏输入 cmd 后按回车
    3. 输入：python main_tk.py
    4. 按回车

【第一次没有 Python 时】

  1. 打开 https://www.python.org/downloads/
  2. 下载并安装 Python 3.10 或更新版本
  3. 安装界面底部勾选：Add python.exe to PATH  （很重要！）
  4. 安装完成后重新双击 run.bat

【正常情况】
  黑窗口闪一下或保持打开均可，会弹出游戏窗口「天下归一」。
  不要关黑窗口也可以；关掉游戏后黑窗口按任意键退出。

【不需要安装】
  本游戏用 main_tk.py，不需要 pygame，一般不用 pip 安装别的库。

【转发时请发送】
  整个 tianxia_guiyi 文件夹（压缩成 zip 再发更方便）

【仍无法启动】
  把黑色窗口里的完整文字截图发给发送者。
